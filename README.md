# AXIOPHYS Website V0

AXIOPHYS Inc. company website, based on the existing PRIME-CAE website implementation. PRIME-CAE remains the product name.

## Preview

Run `python3 -m http.server 8080` and open the local server. Run `python3 build.py` after editing JavaScript source modules.

The original engineering canvases, product graphics, hero footage, navigation, responsive styles and reduced-motion support are preserved. The company identity, About introduction and footer identify AXIOPHYS Inc. as the company behind PRIME-CAE.

No custom domain is configured. Publish only after design approval; do not reuse the PRIME-CAE CNAME.
